# Yatharth Shrirame — Portfolio

Personal developer portfolio for Yatharth Girish Shrirame, an Artificial Intelligence undergraduate at GHRCE.

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production build

```bash
npm run build
npm start
```
