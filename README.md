# Yatharth Shrirame — Portfolio

[![Live Demo](https://img.shields.io/badge/Live%20Demo-yatharthshrirame.xyz-34d399?style=for-the-badge&logo=vercel&logoColor=white)](https://yatharthshrirame.xyz)

Personal developer portfolio for Yatharth Girish Shrirame, an Artificial Intelligence undergraduate at GHRCE. Deployed on Vercel.

## Stack

- Next.js (App Router)
- Tailwind CSS
- Framer Motion
- TypeScript
- Lucide React

## Deployment

The portfolio is deployed via Vercel at [yatharthshrirame.xyz](https://yatharthshrirame.xyz).

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production build

```bash
npm run build
npm start
```
